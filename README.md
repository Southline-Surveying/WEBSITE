# Southline Surveying & Mapping

Static website for southlinesurveying.com. Deployed on Vercel.

- Pages: `index`, `services`, `geospatial`, `industries`, `projects`, `about`, `contact`
- Styles: `css/main.css`  ·  Scripts: `js/main.js`  ·  Images: `assets/`
- Contact form posts to Web3Forms (set the access key in `contact.html`).
